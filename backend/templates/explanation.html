Diptest API

Send requests to https://diptool.lorenz.kiwi/api/dip-from-histo with a json array attached. Each value represents one column in a barchart that represents the histogram. The order will match the order of the columns. The values are read as the shape of a density, not as counts: the dip test runs on an ideal sample of n points placed at the shape's quantiles. Pick n with the query parameter ?n= (10 to 5000, default 200); it only changes the p-value noticeably. Check https://github.com/lor-enz/diptest_interactive for more info.
